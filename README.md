# 奇门演卦馆 · 遁甲断事练习

一个中国传统古典风格的网页应用，用于练习奇门遁甲断事：

1. **迎客问卦** —— 由 AI 模拟一位有血有肉的顾客前来问事（未配置 AI 时使用内置本地题库）；
2. **即时起局** —— 程序按当下北京时间自动排出奇门盘（时家奇门 · 拆补定局 · 转盘飞布）；
3. **依盘断事** —— 你根据盘面为顾客写下断语；
4. **师父点评** —— AI 扮演老师父，给出参考断法、逐项点评、十分制评分与精进建议；
5. **练习历史** —— 每次练习（问题 / 盘面 / 断语 / 点评 / 得分）保存在浏览器本地，可随时回看。

## 使用方法

纯静态页面，无需构建。任选其一：

- 直接双击打开 `index.html`；
- 或本地起个服务：`python3 -m http.server 8000`，访问 <http://localhost:8000>。

## 配置 AI（API Key 后续补充即可）

点击右上角「设 置」，填入：

| 项目 | 说明 |
| --- | --- |
| 接口地址 | OpenAI 兼容接口，填到 `/v1` 为止，如 `https://api.openai.com/v1`、`https://api.deepseek.com/v1`、`https://dashscope.aliyuncs.com/compatible-mode/v1` |
| API Key | 仅保存在本机浏览器 localStorage，不上传任何服务器 |
| 模型名称 | 如 `gpt-4o-mini` / `deepseek-chat` / `qwen-plus` |

填好后可点「测试连接」验证。未配置时也可用内置题库练习，只是没有 AI 顾客与点评。

## 排盘口径说明

- 时间：一律按北京时间（UTC+8）起局，23 时后日柱换日（晚子时起新日）。
- 定局：拆补法——以日干支符头（甲/己日）定三元，以当日所处节气查局。
- 排盘：转盘法——九星随值符转，八门随值使飞，八神阳顺阴逆；中五寄坤二，禽随芮转。
- 节气：采用通行的 1900 年基准天文近似公式（1900–2100 年内交节日期基本准确，交节当日临界时刻可能有分钟级误差）。

```
js/app.js         页面交互与历史记录
```
